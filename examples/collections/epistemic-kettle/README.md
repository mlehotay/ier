# The Epistemic Kettle

## Status

Status: reference
Authority: non-canonical

A variable-temperature kettle provides a small worked example in AI
explainability. Investigators can observe and operate it normally, but cannot
inspect its program. What can behavior and intervention justify them in saying
about how it works?

- [The Epistemic Kettle](epistemic-kettle.md): observation, intervention,
  behavioral equivalence, decomposition and the limits of identifying a program.
- [The Valerian Demon](kettle-valerian-demon.md): a comic rival explanation
  showing why fitting observed behavior does not make every account equally good.

Start with the core article, then read the demon as a humorous challenge to
explanatory shortcuts. These are illustrative arguments, not reports of a
performed kettle experiment. Task success establishes neither experience nor
IER cognition, agency or intrinsic closure. The kettle's programmatic opacity
is distinct from canonical experiential privacy.
