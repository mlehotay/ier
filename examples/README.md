# Examples

Short illustrations of Informational Experiential Realism (IER), intended to
build intuition for the [core theory](../IER/IER-model-overview.md).

Start with the [analogy collection](analogies/README.md), which explores
constraint, boundaries, flow, and regime transitions through familiar systems.

Examples are non-canonical illustrations. They introduce no new theoretical
criteria and do not establish that the systems described instantiate experience.
