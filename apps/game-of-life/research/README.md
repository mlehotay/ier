# Game of Life research

## Status

Status: experimental\
Authority: non-canonical

Native apparatus and bounded model findings are implemented.

Start with [Reproducing the Life relations](relations.md) for exact definitions,
requirements and commands. The public app includes the native checkers,
protocols, complete trajectory bundles and finite-analysis reports. Run
`make research-check-relations` from the app directory to verify them without
private workflow files or Git history.

The relations cover production and installation, access and joint compatibility,
current screening and changing interfaces, response equivalence under declared
action policies, recurrent generators, context-relative support, upkeep/loss and
external restoration. [The native audit dossier](investigations/mechanism-phase4-native-audits.md)
and [feedback dossier](investigations/response-aspect-feedback-017.md) describe
preparations, independent expectations and findings.

Unity follows from the identity proposal, which is not diagnosable. Operating
as one organization is itself a unity question; an independent organization
classifier is not a prerequisite. The native tests do not diagnose identity,
unity, qualification, ownership or full continuity. No biological mechanism is
established by a Life analogy. See the relation reference for each evidence limit.

## Examples and apparatus

The [Life machine](game-of-life-machine.md) introduces the state and update.
Worked [glider](worked-examples/glider.md), [toad](worked-examples/toad.md) and
[loaf](worked-examples/loaf.md) examples provide literal phases and
[starting fixtures](worked-examples/fixtures/). The loaf contrasts persistence
without live-site turnover with the moving/oscillating examples.

The [statistics and recorder contract](persistence-statistics-plan.md)
describes `research-run` and `research-measure`. Exact ON/OFF neighborhood
conditions are exported by `research-production`; paired native comparisons
use `research-cross-cases`. [Tests](../tests/README.md) qualify recording,
measurement, production, fixtures, replay and corrupted-evidence rejection.
All trajectories use the existing C engine; the UI is unnecessary for research.
