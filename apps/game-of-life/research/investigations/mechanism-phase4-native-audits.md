## Apparatus and reproducibility

[research_mechanism.py](../../tools/research_mechanism.py) uses the existing
recorder and `WorldEngine` wrapper around `src/world.c`. No other engine advances
the boards. Independent oracles are the closed-form 3×3-torus truth relation,
explicit local neighbor counts and literal glider/toad/block phases. A target
truth predicate is used only to check native outputs, not to generate a trajectory.

```bash
make research-mechanism OUTPUT_DIR=research/investigations/runs/2026-11-17-mechanism-phase4
make research-check-mechanism RUN_DIR=research/investigations/runs/2026-11-17-mechanism-phase4
make test-mechanism
```

Run from the app directory. Creation refuses an existing directory; the second
command verifies existing evidence read-only. To reproduce, choose a new output
directory. The saved [results.json](runs/2026-11-17-mechanism-phase4/results.json)
indexes exact source and artifact hashes, including 61 input manifests/native
traces, the protocol, context and 512 exact ON/OFF production exports. The full
bundle is about 2.3 MiB. Recorder headers identify actual native source/library
fingerprints and the Git baseline; new working-tree code is identified by its
file hashes, not falsely claimed to exist in that baseline commit.

The verifier checks the declared inventory, source/protocol/proposal/fixture
identities, trace lifecycle, native replay, independent expected outputs,
production locations/inputs/occurrence counters and recomputed findings. It
rejects modified findings, rehashed fixture changes, forged production targets,
incomplete or extra artifacts and overwriting an earlier run. Failure to load
the engine cannot create a complete aggregate. Software tests reconstruct two
fresh bundles and compare them, then verify without modifying saved evidence.

## Why transition representation does not diagnose unity

The weak representation is universal for a deterministic state update:
for a chosen cut A/B, write the native outputs as F_A(x_A,u_A) and
F_B(x_B,u_B), where each u is the required neighboring state from the other
side. Every output computation remains in its original local rule. Responsive
boundary messages can reproduce feedback. This statement concerns a transition
representation, not independent production of maintained organizational aspects.
The exhaustive family verifies that distinction in a finite native setting.

Native action, causal uptake and an actual maintained physical condition are
stronger descriptions than unrestricted transition representation. Concatenating
two readouts into one tuple, prohibiting responsive services, or assigning a
preferred pattern label does not establish those physical facts. Keeping the
native producer usefully distinguishes actual updates from installation, but
a partition can retain its local native updates too; provenance does not select
one constitutive scope.

The separate organization-classifier requirement is withdrawn. The representation
result remains a limitation on what these measurements imply, not a failed unity
experiment, an empirical absence of Life organization or a claim that physical
inquiry cannot constrain proposed explanations. No organizational oracle was
installed in the analyser.

## Biological and physical interpretation

The native comparisons test the stated general relations, not Rab/ESCRT,
Ran gradients or motor chemistry. Independent definition and correspondence
are needed to transfer them: input-bit compatibility is not automatically
competition for molecular capacity; OFF restoration is not material constraint
turnover; moving sites are not cargo transport; installed boards are not every
physical replacement. This bundle establishes none of the source-specific biochemical translations.
A bridge between the plant activation and retromer studies is not supplied by
these generic model comparisons.

Abstract role/input relations, their C execution and the host's actual physical
maintenance are distinct. No host characteristic timescale, dissipative mechanism,
continuous owned closure or intrinsic informational tension was tested. The
universal transition representation is not restored successor-support
factorization as a necessary unity condition.
