# Informational Experiential Realism (IER)

IER is a physicalist theory of experience. Its central claim is:

> Experience is identical to the operation of a physical system organized as a globally integrated, temporally extended regime under intrinsic constraint.

This public repository contains the core theory, worked examples, and exploratory
applications.

## Project details

IER is an active research project in the v10.11.6 development era. Physical
instantiation, empirical attribution of experience, qualitative correspondence,
and the abductive defense of identity remain open research questions.
