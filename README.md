# Informational Experiential Realism (IER)

IER is a physicalist theory of experience. Its central claim is:

> Experience is identical to the operation of a qualifying Unified Experiential Field: a physically individuated operation with intrinsic closure, non-externalizable ownership, constitutive membership, and produced-and-inherited continuity.

The identity proposal is abductive and a posteriori. Coupling, coordination,
mechanical load-bearing, or persistence alone does not establish qualification.

This public repository contains the core theory, worked examples, and exploratory
applications.

## Start reading

Begin with the [Model Overview](IER/IER-model-overview.md). Then read the
[Specification](IER/IER-specification.md) for the defining criteria and
[Theory](IER/IER-theory.md) for the argument. [Constraint](IER/IER-constraint.md)

For an intuitive introduction, try [Hello World](IER/IER-hello-world.md),
[Below Hello World](IER/IER-below-hello-world.md), or the
[analogy examples](examples/analogies/README.md). Hello World supplies schematic
intuition; it is not a completed physical instantiation. The
[Learning IER: A Guided Annotated Reading List](IER/IER-bibliography.md) supplies a beginner sequence and optional branches. The [philosophical reading map](apps/philosophy/IER-philosophy-of-mind-curriculum.md) organizes sources by argument and question.

## Project details

IER is an active research project in the v10.11.7 development era. Physical
instantiation, empirical attribution of experience, qualitative correspondence,
and the abductive defense of identity remain open research questions.
